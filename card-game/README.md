# Uno Card Game

A single-file, browser-based Uno-style card game. Play against a simple computer opponent.

## Play

Open `index.html` in any browser. No build step or server required.

## Rules implemented

- 2-player (you vs. computer), standard 108-card Uno deck
- Number, Skip, Reverse, +2, Wild, and Wild+4 cards
- Skip/Reverse act as "play again" in 2-player mode
- Draw pile reshuffles from the discard pile when empty
